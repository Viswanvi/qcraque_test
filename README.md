# Bill Splitter

A small web app that splits a bill (with optional tip) between people.

## Features
- Splits the total bill equally, including an optional tip
- Validates input: amount must be > 0, people must be a whole number ≥ 1, tip 0–100%

## How to run
1. Download or clone this repository
2. Open `index.html` in Chrome or Edge
3. Enter the amount, number of people and tip, then click "Split the bill"
